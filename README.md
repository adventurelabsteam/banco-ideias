# banco-ideias

Banco de ideias por projeto: manda **áudio, texto ou foto** por um atalho do celular e a ideia cai, transcrita, num banco bruto isolado por projeto. Depois uma IA faz a triagem.

**Status:** planejamento. As decisões estão sendo tomadas no mapa (issue `[MAP]`), um ticket por vez.

- O repositório é público; **os dados não são**. Nada de dado, mídia ou credencial aqui. Segredos ficam em variáveis de ambiente (veja `.env.example` quando existir).
- Decisões duráveis vão para `docs/adr/`.
